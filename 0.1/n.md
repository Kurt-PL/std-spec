# §N. Name and orthography

This annex is not part of the normative specification. It defines the pronunciation and orthographic representations of the name of the Kurt programming language across writing systems.

## N.1 Origin

The name honours Kurt Gödel (1906–1978), who in 1931 exhibited a sentence true of the natural numbers that no consistent, effectively axiomatized theory of arithmetic proves.

The language was known during development by four working names:

— **Lovelace** — the title borne by Augusta Ada Byron (1815–1852), known as the first programmer.

— **Augusta** — the given name of the same person.

— **Shannon** — for Claude Shannon (1916–2001), the founder of information theory.

— **Seanáin** — the personal name in *Ó Seanáin*, the Irish form from which the surname Shannon derives.

## N.2 Pronunciation

The canonical pronunciation is /kʊɐ̯t/. It follows Austrian German, the phonology of the man the name honours, in which a post-vocalic /r/ is realized as a vocalized /ɐ̯/. The following approximations are acceptable in other phonological systems:

The name is one syllable in the canonical pronunciation. None of Korean, Japanese, and Mandarin admits a syllable that ends in a released /t/, so an adaptation to any of them carries an epenthetic vowel and more than one syllable.

## N.3 Orthographic representations

The name is written as follows in each script. In the Latin script it takes an initial capital and the remainder lowercase.
