# §N. Name and orthography

This annex is not part of the normative specification. It defines the pronunciation and orthographic representations of the name of the Kurt programming language across writing systems.

## N.1 Name

The name of the language is **Kurt programming language**, and its short name is **Kurt**. The language was known during development by several working names — Lovelace, Augusta, Shannon, Sionann. The name honours **Kurt Gödel** (1906–1978), whose incompleteness theorems established fundamental limits on formal systems.

## N.2 Pronunciation

The canonical pronunciation is /kʊɐ̯t/, following Austrian German phonology. Kurt Gödel was born in Brünn and lived in Wien; the Austrian German realization of the post-vocalic /r/ as a vocalized /ɐ̯/ is therefore the historically correct pronunciation. The name is one syllable in the canonical pronunciation. Adaptations to syllable-timed languages (Korean, Japanese, Mandarin) necessarily introduce additional syllables; this is expected and correct.

A conforming implementation’s documentation and diagnostics should use the Latin representation “Kurt”. Translations into Korean, Japanese, or Mandarin should use the representations given above.

## N.4 Typographic conventions

In running text, the short name is written as **Kurt** (capitalized, roman). It is not written as KURT, kurt, or kUrT.
